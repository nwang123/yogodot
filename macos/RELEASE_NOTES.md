## 下载

macOS 13+：M 系列芯片选 `arm64`；Intel 芯片选 `x86_64`。解压后把 `YogoDot.app` 放进「应用程序」，退出旧版再打开新版。

应用采用临时签名，尚无 Apple Developer ID 公证。真实键盘上的 USB / 2.4G 与休眠恢复仍待实机验证。无需关闭系统安全保护。详见 README。
